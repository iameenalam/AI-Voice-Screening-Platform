# Vocalent

**Vocalent** is an AI-powered **voice screening platform** designed to help recruiters streamline candidate evaluation. It enables hiring teams to manage job openings, upload and parse CVs, invite candidates to voice interviews, and review transcripts and AI-generated screening results in one intuitive platform.

## Features

- **Candidate and CV Management:**  
  Upload candidate CVs, extract relevant details, and organize applicants in a centralized candidate pool.

- **AI-Powered CV Screening:**  
  Use artificial intelligence to analyze CV content and extract structured candidate information for faster screening.

- **Voice Interviews:**  
  Conduct structured voice-based interviews with configurable screening questions and microphone testing.

- **Interview Invitations:**  
  Send personalized interview invitations to candidates through email using shareable interview links.

- **AI Interview Analysis:**  
  Transcribe candidate responses and generate screening insights, scores, and recommendations to support hiring decisions.

- **Recruiter Dashboard:**  
  View jobs, candidates, interviews, applications, transcripts, and screening results from a single dashboard.

- **Public Candidate Experience:**  
  Candidates can apply for roles and complete interviews through public, token-protected interview pages without needing a recruiter account.

## Tech Stack

- **Frontend:** React, Vite, TypeScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **AI Intelligence:** OpenAI API through OpenRouter
- **Styling:** Tailwind CSS
- **UI Components:** Radix UI, shadcn/ui
- **Routing and Data Fetching:** React Router, TanStack React Query
- **Authentication:** JSON Web Tokens, bcryptjs
- **Voice Transcription:** Transcription API integration
- **File Uploads:** UploadThing, Multer
- **Document Processing:** PDF Reader, Mammoth, Tesseract.js
- **Email:** Nodemailer
